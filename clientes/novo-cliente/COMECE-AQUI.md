## Antes de qualquer coisa

1. **Renomeie a pasta** pro slug do cliente:
   ```bash
   git mv clientes/novo-cliente clientes/nome-da-clinica
   ```
2. Preencha o `README.md` (capa) — nome, decisor, nicho, cidade, ticket, dono.
3. Registre o cliente na tabela "Ativos" de `clientes/README.md`.
4. Apague este arquivo.
