# Logo NEXUS

Monograma "N" da NEXUS: barra diagonal + dois quadrados arredondados, em gradiente
verde (lima → teal) sobre dark-mode.

## Arquivos

| Arquivo | Uso |
|---|---|
| `nexus-logo.svg` | **Vetor, fundo transparente.** Fonte editável, usar sempre que possível. |
| `nexus-logo.png` | Raster 1024×1024, fundo transparente. |
| `nexus-logo-darkbg.svg` | Vetor com fundo dark (#0B1220), para preview/apresentação. |
| `nexus-logo-darkbg.png` | Raster 1024×1024 com fundo dark. |

## Cores

- Gradiente: **#DFF7A0** (lima) → **#5CE39A** → **#00BFA5** (teal — cor principal da marca).
- Fundo dark de referência: **#0B1220**.
