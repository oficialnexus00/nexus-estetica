## Regras de decisão

| Situação | Ação |
|---|---|
| CPL > 2× meta em 3 dias com R$ gasto ≥ 3× CPL alvo | Pausa o criativo |
| CTR < 1% | Problema é criativo/hook |
| CTR ok + CPL alto | Problema é oferta |
| CPL ok + agendamento baixo | Problema é o agente / atendimento |
| CPL ok + show baixo | Problema é confirmação / qualificação |
| Conjunto vencedor achado | Duplica com +50% verba, não mexe no original |
