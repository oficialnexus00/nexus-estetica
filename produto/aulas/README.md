# Aulas — material didático

## Anatomia da Toxina
Deck de 17 slides para especialização em toxina botulínica.
Estrutura: capa em corte estratificado → as 5 camadas da face → mapa dos 11
músculos → um slide por músculo → conversão entre produtos → regras de
prevenção de complicações.

- `Anatomia-da-Toxina.pptx` — o deck (16:9, com notas do apresentador)
- `anatomia-toxina.build.js` — gerador. Editar aqui e rodar `node` regera o
  deck inteiro; nunca editar o pptx e o script em paralelo.
- Versão web interativa: artefato "Anatomia da Toxina"

Todas as doses em unidades de onabotulinumtoxinA. Material de apoio didático —
não substitui atlas anatômico nem a bula do produto.
